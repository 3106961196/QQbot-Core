## 权限说明（官方口径，标注处待复核）

- Markdown / Ark / Embed / 语音 / 视频 / 文件 / 主动消息 / 消息审核：不同能力在开放平台有不同申请门槛，部分需要审核或白名单。
- 群管理（禁言/踢人/角色/频道管理）、互动（反应/置顶/公告）：需要机器人具备相应权限（管理员等）。
- 音频/直播、帖子论坛、日程：官方文档标注为白名单/低频能力。

> 说明：上表"⚠️ 待确认"项 = 当前无法单凭本仓库确认官方对该能力的准确申请条件，未编造；以官方文档实际页面为准。
